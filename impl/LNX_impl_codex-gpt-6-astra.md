## 아키텍처
Linux CLI는 기존 make_subtitle 모듈의 공통 기능을 재사용한다.
설치 스크립트는 프로젝트 tools/ 안에 CPU용 엔진을 빌드한다.

## 핵심 설계 결정
플랫폼별 진입점과 문서 분리, macOS 동작 유지, 대용량 산출물 제외.

## 진행 기록
- LNX-M1: Linux 진입점 분리와 공통 기능 import 완료. 기본값 격리 및 CPU 옵션을 테스트했다.
- LNX-M2: 플랫폼별 문서, 설치 스크립트 및 Git 제외 규칙을 추가했다.
- LNX-M3: Linux 5개 테스트와 기존 외국영화 자체검증 통과. 통합 진입점으로 실제 10초 영상에서 4개 대사 SRT/SMI를 생성했다.
- 실제 실행은 기존 kor_linux 엔진을 PATH에 지정해 확인했다. 대상 프로젝트 자체 엔진 빌드도 진행 중이며 종료 후 별도로 확인한다.

없음.

## 검증 결과
Linux 5개 검사 및 기존 외국영화 검사 통과. 기존 macOS/Finder/외국영화 소스 diff 없음. 실제 모델 연동 성공.
