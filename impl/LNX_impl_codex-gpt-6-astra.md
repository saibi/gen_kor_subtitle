## 아키텍처
Linux CLI는 기존 make_subtitle 모듈의 공통 기능을 재사용한다.
설치 스크립트는 프로젝트 tools/ 안에 CPU용 엔진을 빌드한다.

## 핵심 설계 결정
플랫폼별 진입점과 문서 분리, macOS 동작 유지, 대용량 산출물 제외.

## 진행 기록
- LNX-M1: Linux 진입점 분리와 공통 기능 import 완료. 기본값 격리 및 CPU 옵션을 테스트했다.
- LNX-M2: 플랫폼별 문서, 설치 스크립트 및 Git 제외 규칙을 추가했다.
- LNX-M3: Linux 9개 테스트와 기존 외국영화 자체검증 통과. 통합 진입점으로 실제 10초 영상에서 4개 대사 SRT/SMI를 생성했다.
- 초기에는 기존 엔진으로 smoke test를 수행했다. 이후 프로젝트 자체 엔진 빌드 성공, 별도 PATH 설정 없이 SHA-256 검증을 거쳐 10초 구간/4개 대사 SRT·SMI 생성 성공을 확인했다. 이 실행은 성능 비교용이 아닌 통합 검증이다.
- Claude Sonnet 5.5 교차리뷰 후 버전 고정, 검증 다운로드, 일괄 처리 오류 격리, 출력 충돌 검사, 이식성 테스트를 보완했다.

## 계획 대비 변경
공통 다운로드/캐시 함수는 그대로 가져오는 대신 Linux 래퍼로 감싼다.
리뷰에서 공유 /tmp 모델 자동 가져오기와 무결성/동시 다운로드 문제가 확인되어
원본 macOS 파일을 바꾸지 않고 명시적 캐시 경로, SHA-256 검증, 독립 임시 다운로드를 추가했다.
그 밖에 검증 리비전 고정과 일괄 처리 오류 격리/충돌 검사를 추가했다.

## 검증 결과
Linux 9개 검사 및 기존 외국영화 검사 통과. 기존 macOS/Finder/외국영화 소스 diff 없음. 프로젝트 자체 엔진으로 실제 모델 연동 성공. bash -n 및 설치 재실행 성공. 테스트는 모델 다운로드나 추론을 자동 실행하지 않으며 ffmpeg가 없으면 오디오 추출 검사만 skip한다.
